# Update the AI log

1. Read `docs/AI_LOG.md`. If it does not exist, create it with `# AI Log`.
2. Find the current milestone section and add it if missing.
3. Ask the student to confirm the AI tool/model used, the task, and the main prompt if those details are unknown.
4. Propose an entry under `### Tools and tasks` including tool/model, task, the exact or accurately paraphrased prompt, what was generated, and what the student kept/changed/rejected.
5. Ask whether the AI was wrong or produced poor code. Record at least two real cases per milestone as required by the course, including what was wrong, how it was noticed, and how it was fixed.
6. Never invent prompts, tools or mistakes. If something is unclear, ask.
7. Show the proposed entry and wait for confirmation before saving it.
